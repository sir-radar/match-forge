# Feature portfolio and gated dependencies

**Proposed research order; NOT a delivery commitment or blanket authorization.** Use [actual experiment register](experiment-register.md) and owner decision events, not the wording of this document, to determine permission.

| Family | Prior dependency | Scientific question and mandatory ablation | Recorded permission | Production state |
| --- | --- | --- | --- | --- |
| Existing goals-only/dynamic references | Audited current code, PIT fixtures | Reproduce without altering frozen Sprint 2 results | Existing work; verify before use | Not recorded as production-enabled |
| One minimal Phase 3A xG goal-model hypothesis | Approved Tier-A + exact owner event | Narrow hypothesis exactly as authorized; no automatic xGA suite | Research only, already recorded | Not promoted |
| Broader xG/xGA/shot/opponent/game-state | Qualified events, same features, new owner scope | A–F suite + raw/state ablations, proper-score and calibration comparisons | New decisions required | Not established |
| Travel, rest, dynamic/context | Reliable venue/time/manager data | Objective components, one-family ablation | New decisions required | Not established |
| Residual H2H/matchup | Historical out-of-sample forecasts and IDs | Shrunk pair effect vs no H2H; no degradation without pair history | New decisions required | Not established |
| Derby and risk labels | Reviewed registry and past OOS residuals | Descriptive tag validity/coverage and parity; no forecast effect | Scope approval needed | Display only, once separately enabled |
| Predicted/confirmed lineup and squad | Qualified player identities and point-in-time announcements | Scenario deltas, coverage/fallback and continuity | New decisions required | Not established |
| Goalkeeper post-shot | Qualified xGOT/keeper data | Shrunk incremental post-shot effect vs team xGA | New decisions required | Not established |
| Pre-shot threat/territory | Qualified sequences | Box entries/turnovers vs xG baseline | New decisions required | Not established |
| Horizons/revisions | Source publication history | Value of newly eligible information by horizon | New decisions required | Not established |
| Ensemble | Separately useful OOS models + calibration window | Ensemble vs simple and equal-weight models | New decisions required | Not established |
| Minimal Rust validation | Coherent sealed distribution + distinct owner decision | Analytic parity, confidence half-width, tails, determinism and cost | **Separate new authorization needed** | Mandatory for new production only **after** acceptance/activation |
| Advanced simulation scenarios | Accepted minimal Rust + qualified scenario data | Separate scenario-specific parity and real-outcome predictive test where proposed | Separate new decisions required | Not established |

Feature families are sequenced by *evidence dependencies*, not all necessarily sequential by calendar: a properly authorized minimal Rust reference sampler can be developed alongside probability foundations without blocking the authorized analytic Phase 3A study. Failed experiments remain failed; no silent combination or post-hoc threshold tuning. Derby and uncertainty labels stay outside forecasting regardless of descriptive study findings.

For source detail see [feasibility matrix](feasibility-matrix.md), [model research](../models/feature-research.md) and [Evaluation V2](../evaluation/evaluation-v2-policy.md).
